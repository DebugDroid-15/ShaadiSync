# ShaadiSync — Intellectual Property, Patents, and Licensing Strategy

## 1. Executive Summary
- **Project Identity:** ShaadiSync
- **Rights Holder Designation:** Team SHATRUJEET (Amar Khera, Ananya Rout, Lucky Kumar, Omm Prakash Sahoo)
- **Status:** Proprietary closed-source software. Unsigned draft licensing pending contributor agreements and independent legal review.
- **Canonical Repository:** `https://github.com/DebugDroid-15/ShaadiSync`

## 2. Contributor Agreements and Ownership Status
- All code, documentation, schemas, and UI designs authored for ShaadiSync are intended to be proprietary works owned collectively by Team SHATRUJEET.
- An explicit Contributor Assignment Agreement (CAA) and Non-Disclosure Agreement (NDA) must be executed among all founding team members before commercial launch or public distribution.
- Git commits or code submissions do not independently substitute for written IP assignment deeds under the Indian Copyright Act, 1957.

## 3. Patent & Technical Inventions Review
- **Patent Claim Status:** No patent application is currently filed. The project is NOT "patented", "patent pending", or "patent protected".
- **Distinction of Ordinary vs Novel Software:**
  - Standard CRUD operations, UI interfaces, relational schemas, and third-party integrations (e.g., standard QR code generation or WhatsApp link formatting) are standard software engineering patterns and are not considered novel patentable inventions.
  - Potential patentability review will focus strictly on genuinely novel multi-event guest-graph synchronization algorithms, deterministic offline-first multi-gate check-in conflict resolution, or proprietary banquet-yield prediction engines if and when engineered.
- **Confidentiality Preceding Review:** Prior to any technical invention disclosure or public release, professional counsel under Indian patent law (specifically Section 3(k) of the Indian Patents Act, 1970 regarding Computer Related Inventions) must be sought.

## 4. Trademark Considerations
- The mark **"ShaadiSync"** and associated logos, taglines, and brand marks are intended brand identifiers of Team SHATRUJEET.
- A comprehensive trademark search under Class 42 (SaaS) and Class 41/35 (Event Management Services) in the Indian Trademark Registry must be conducted prior to commercial marketing.

## 5. Third-Party Software Inventory
- Standard open-source frameworks (Next.js, React, TypeScript, Tailwind CSS, Supabase libraries, Vitest) are incorporated under their respective MIT/Apache-2.0/ISC licenses.
- No viral copyleft (GPL / AGPL) libraries are permitted in the dependency tree to prevent contamination of the proprietary codebase.

## 6. Repository Visibility & Confidentiality Controls
- Canonical repository is hosted on GitHub.
- Recommend keeping repository private until formal team and legal authorization.
- Branch protection and code review rules must be enforced for `main`.
- Absolutely no production credentials, API secrets, or personal guest data are permitted in the repository.
